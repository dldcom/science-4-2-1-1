# 나만의 달 꾸미기 — Art Bible

## 1. 한 줄 시각 방향

초등 과학 수업에서 아이가 직접 달 표면을 만들어 보는 **포근한 우주 공방**.

- 달과 지구는 둥글고 친근한 3D 오브젝트로 보여 준다.
- 우주 배경은 깊은 남색으로 유지하되, 조작 UI는 따뜻한 크림색과 파스텔 보라색으로 구분한다.
- 화면의 주인공은 항상 달이다. UI가 달을 덮거나 시선을 빼앗지 않는다.
- 대시보드·SaaS·마케팅 랜딩페이지처럼 보이지 않는다.
- 어린이가 읽기 쉬운 짧은 문장과 큰 버튼을 사용한다.

## 2. 교육적 핵심

제작 화면은 관찰 화면에서 배운 내용을 직접 적용하는 단계다.

1. 운석이 달에 부딪히면 충돌 구덩이가 생긴다.
2. 충돌로 생긴 웅덩이에 뜨거운 용암이 흐를 수 있다.
3. 용암이 식으면 어두운 암석 영역이 된다.
4. 달의 바다는 물이 아니라 어두운 암석 평원이다.

색상 선택, 자유 장식, 꾸미기 아이템 상점은 사용하지 않는다.

## 3. 형태 언어

- 달·지구·운석은 둥근 실루엣을 우선한다.
- UI 패널은 큰 둥근 모서리와 얇은 안쪽 점선 테두리를 사용한다.
- 버튼은 손가락으로 누르기 쉬운 넓은 영역을 갖는다.
- 크레이터는 완전한 원보다 가장자리와 깊이가 보이는 둥근 움푹한 형태로 표현한다.
- 달의 바다는 원형 스티커처럼 보이지 않도록 낮은 불투명도의 곡면 패치로 표현한다.
- 장식용 아이콘은 꼭 필요한 조작 의미가 있을 때만 사용한다.

## 4. 색상 토큰

### 공간

- `space-950`: `#050B24` — 전체 우주 배경
- `space-900`: `#0A1640` — 장면의 깊은 영역
- `space-800`: `#12245A` — 보조 배경
- `star`: `#FFF2C6` — 별과 따뜻한 강조

### 달과 지구

- `moon-base`: `#D9D2C2` — 달의 기본 밝은 암석
- `moon-light`: `#F2E9D1` — 빛을 받는 가장자리
- `moon-shadow`: `#8E8A89` — 달의 그늘
- `mare-dark`: `#4B4A50` — 달의 바다
- `earth-ocean`: `#399DD3` — 지구의 바다
- `earth-land`: `#74B968` — 지구의 육지

### UI

- `panel-cream`: `#FFF0D4` — 설명 패널
- `panel-cream-deep`: `#E9C89C` — 패널 안쪽 구분선
- `lavender`: `#9E8BD6` — 보조 버튼과 선택 전 상태
- `teal`: `#19B6B5` — 운석 선택과 학습 강조
- `coral`: `#F56D5D` — 제작 완료와 중요한 진행 버튼
- `ink`: `#332F47` — 패널 본문 글자
- `ink-muted`: `#716A7E` — 보조 설명

## 5. 조명과 재질

- 달은 거친 표면의 `MeshStandardMaterial`을 사용한다.
- 달의 바다는 완전히 검은색이 아니라 보랏빛 회색의 낮은 대비 영역으로 표현한다.
- 달의 가장자리에는 아주 약한 푸른 대기광을 둔다.
- 운석 충돌 순간에만 짧은 주황색 빛과 작은 충격 링을 보여 준다.
- 용암은 일시적으로 따뜻한 주황색으로 흐르고, 완료 후에는 자동으로 어두운 암석 영역으로 바뀐다.
- 과한 bloom·후처리·현란한 파티클은 사용하지 않는다.

## 6. 캐릭터 방향

- 2.5D 동물 우주 비행사 안내 캐릭터를 사용한다.
- 얼굴은 패널 오른쪽 위나 화면 가장자리에 작게 배치한다.
- 캐릭터는 설명을 보조하며, 달보다 커지지 않는다.
- 표정 변화는 기본·응원·완료 정도의 소수 상태만 필요하다.
- 캐릭터가 없어도 교육 문구와 조작이 이해되어야 한다.

## 7. 제작 화면 구성

### 데스크톱·태블릿

- 화면: `Viewport-fixed`, 기본 문서 스크롤 없음
- 상단: 짧은 제목과 처음 화면 버튼
- 중앙: 달 3D 장면, 달 오른쪽 아래에 작은 지구
- 좌측 또는 장면 가장자리: 세로 조작 도구
- 우측: 크림색 설명 패널
- 패널 순서:
  1. 현재 단계와 진행 표시
  2. 운석 충돌 버튼
  3. 용암 흐르기 버튼
  4. 짧은 교육 설명
  5. 제작 완료 버튼

### 모바일

- 화면: `Viewport-fixed`, 세로 한 화면 조작
- 상단 헤더는 짧게 유지
- 달 장면은 위쪽 55~60%를 차지한다.
- 하단 조작 패널은 고정된 영역으로 배치한다.
- 버튼은 가로 한 줄 또는 세로 두 줄로 재배치한다.
- 조작 패널 내용이 길어지면 패널 내부만 스크롤한다.
- `env(safe-area-inset-*)`을 최상위 셸에 한 번만 적용한다.

## 8. 조작 규칙

### 운석 모드

- 운석 모드를 선택한다.
- 달 표면을 누르거나 클릭한다.
- 해당 위치에 크레이터가 하나 생긴다.
- 최대 크레이터 수를 제한해 모바일 성능을 보호한다.

### 용암 모드

- 용암 모드를 선택한다.
- 이미 만든 크레이터를 누른다.
- 해당 크레이터에 용암이 흐른다.
- 용암이 식으면 같은 영역이 자동으로 어두운 달의 바다가 된다.
- 크레이터가 없을 때는 용암을 만들 수 없고, 짧은 안내를 표시한다.

## 9. 결과와 업적

결과 화면은 지구 옆에 완성된 달을 보여 준다.

판정 가능한 업적만 사용한다.

- **깔끔한 달 상**: 크레이터 0개, 달의 바다 0개
- **달의 바다 상**: 달의 바다 영역이 3개 이상
- **별똥별 파티 상**: 크레이터 8개 이상
- **울퉁불퉁 달 상**: 크레이터가 최소 3개 표면 구역에 분포

업적은 장식용 문구가 아니라 상태값에서 계산한다.

## 10. 타이포그래피

- 한국어 본문: `Noto Sans KR`, `Apple SD Gothic Neo`, `system-ui`
- 제목: 굵고 짧게, 한 화면에서 두 줄을 넘기지 않는다.
- 본문: 14~17px, line-height 1.55 이상
- 버튼: 최소 14px, 굵은 글씨
- 보조 상태: 11~12px
- 모노스페이스 우주 관제 문구는 기존 관찰·형성 화면에만 제한적으로 사용한다.
- 제작 화면의 교육 문구와 조작 문구는 어린이용 일반 글꼴로 통일한다.

## 11. 모션

- 달은 아주 천천히 회전한다.
- 운석은 짧게 다가와 충돌하고, 충격 링이 한 번 확장된다.
- 용암은 경로를 따라 짧게 흐른다.
- 버튼 선택 상태는 색상과 테두리로 명확히 보인다.
- `prefers-reduced-motion`에서는 달 자동 회전과 충돌 연출을 줄인다.

## 12. 금지 사항

- 대시보드식 통계 카드 나열
- 읽기 어려운 작은 HUD 문구
- 임의의 색상 선택기
- 장식품·스티커·상점 UI
- 실제 달의 바다를 파란 물로 표현하는 것
- 달을 가리는 큰 모달과 팝업
- 교육 내용과 무관한 퀴즈·질문형 관찰 문구
- 외부 이미지에 의존하는 코드 없는 장면
- 모바일에서 주소창·홈 인디케이터에 가려지는 버튼
